# Lagos Rush: Asset Registry

Almost nothing in Lagos Rush is a file someone else made. Textures, cars, buildings, billboards, sounds and music are generated by our own code on the player's device, which keeps the download small and leaves very little to license. What does come from outside is listed here, checked on 7 October 2026.

Status: GREEN means the licence is explicit and our use fits it. YELLOW means usable with an open question. RED never ships.
