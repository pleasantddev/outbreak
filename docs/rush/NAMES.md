# Lagos Rush: Names for approval

Every invented name in the game, with the language it comes from and what it means. Two rules apply now:

- Each name sits in one language. A Hausa first name never gets a Yoruba nickname, and a maker and its model share a language.
- The names spread across languages. Yoruba still shows up most in places and street culture, because the game is set in Lagos, but the invented brands and people are split between Yoruba, Igbo, Hausa and Pidgin.

Everything below is already in the playtest build, so you can see it in place. All of it is a proposal; change anything and I'll swap it in. Where I'm less sure of a meaning, it says so. Please have a native speaker check those.

## Rival drivers

First names come in equal thirds: Yoruba (Tunde, Femi, Kemi, Bola, Segun, Funmi, Dayo, Tola, Yemi, Kunle, Sola, Bisi), Igbo (Ngozi, Chidi, Emeka, Ike, Ada, Uche, Obinna, Nneka, Chioma, Ifeanyi, Amaka, Kelechi) and Hausa (Aisha, Zainab, Musa, Halima, Sani, Usman, Hauwa, Bashir, Aminu, Fatima, Ibrahim, Maryam).

About half get a nickname. Some nicknames belong to one language and only go with names from it:

- Yoruba: Agbero, Gbedu, Owambe, Molue
- Igbo: Odogwu, Agu, Ugo
- Hausa: Zaki, Gudu, Damisa (leopard)

The rest work with any name: Speed, Express, Bridge, Third Mainland, Danfo, Okada, Turbo, Sharp Sharp, Wahala, Japa.

So you get "Emeka Odogwu" or "Aisha Express", but never "Aisha Owambe".

## Your starting name

A new player is given one of these until they type their own: Kola, Amaka, Musa, Seyi, Chinedu, Zainab, Bimpe, Ifeoma, Sani, Tobi, Obinna, Halima.

## Crews

Oshodi Kings, Ikeja Night Runners, Mushin Motorworks, Isolo Drift Club, Ilupeju Iron, Agege Express, Surulere Sliders, Yaba Hustlers. These are Lagos neighbourhoods with English words. Yaba Hustlers replaces Yaba Tech, which is the nickname of a real college.

## Places and signs

Real Lagos places keep their real names: Oshodi, Agege Motor Road, Ikeja, Mushin, Isolo, Apapa, Oworonshoki, Cappa. Shop signs mix the way Lagos streets do: Iya Basira Bukka, Alhaji Sule Foodstuff, Jehovah Jireh Tailoring and so on. Each sign is one shop, one language.
