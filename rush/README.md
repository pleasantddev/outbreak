# LAGOS RUSH

**Arcade street racing on the real roads of Oshodi.**

Slide a Tokunbo under the skywalk, thread danfos and kekes across the expressway bridges, and take the flag past the three terminals of the Oshodi Transport Interchange. Up to twelve cars per room, quick match or a private room with your crew, and no real money anywhere.

The roads and buildings come from OpenStreetMap. Every texture, car, billboard, engine note and beat is generated by the game's own code, so the whole thing downloads in under a megabyte compressed.

![Terminal 3 and the cable stayed skywalk at noon](../docs/rush/screens/terminal3-bridges.jpg)

## Run it

You need Node 20 or newer.

```bash
cd rush
npm install
npm run build     # typecheck and build the client into dist/
npm run server    # rooms, the built client and /health on http://localhost:8787
```

Open http://localhost:8787. For client work with hot reload, run `npm run server` in one terminal and `npm run dev` in another, then open http://localhost:5174; the dev client talks to the room server on port 8787.

`npm start` builds and serves in one go. Set `PORT` to change the port and `QUIET=1` to silence room logs.

## Play

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Drive | W A S D or arrows | Triggers and left stick | Steering pad, GAS, BRAKE |
| Drift (Gbedu) | Space | RB or A | DRIFT |
| Fuel boost | Shift | B or X | FUEL |
| Use item | E | LB or Y | ITEM |
| Look back, camera | C, V | Right stick click | |
| Tow truck | R | | |
| Menu | Escape | Start | |

Hold drift through a bend until the sparks turn pink, then let go. Near misses, drifts, air and slipstream fill Fuel. Drive through the Ghana Must Go bags for items.

Invite a friend with the share button in the lobby, or send them `http://your-host/?room=LAGOS-1234`. If the game stutters on a phone, open Settings and choose Auto or a lower preset, or add `?gfx=low` to the address.

## Test

```bash
npm test                                   # simulation, protocol, room server, rewards and Auto graphics (Vitest)
npm run typecheck
node tools/playtest.mjs http://localhost:8787 out solo    # scripted browser playtest with screenshots
node tools/playtest.mjs http://localhost:8787 out online 640 360 potato   # two players in one room
node tools/bandwidth.mjs ws://localhost:8787/ws            # what an online race costs a player
```

## Rebuild the map

```bash
npm run gis:fetch   # download the Oshodi extract from the Overpass API and record provenance
npm run gis:build   # project, clean and route it into public/world/*.json
```

## Where things are

| Path | What |
|---|---|
| `src/shared` | The race simulation, cars, items, AI, traffic, tracks, protocol: shared by client, server and tests |
| `src/render` | three.js renderer: city, terminals, cars, effects, garage, presets |
| `src/game` | Race session, replay player, input, the stage that holds the city |
| `src/ui` | Screens, HUD, styles |
| `src/net` | Room client |
| `server` | Room server |
| `tools` | GIS pipeline, playtest, bandwidth meter, screenshot helper |
| `../docs/rush` | Design, UI, architecture, rights, graphics, the future regulated module note, asset registry, QA |
